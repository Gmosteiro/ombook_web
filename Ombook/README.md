# Ombook Web

## Overview

This repository contains the web application for Ombook.

## Branching Strategy

### Branch Types

- **`develop`**: Represents everything that's currently in development
- **`main`**: Production-ready code

## Development Workflow

### Creating Feature Branches

1. Create a feature branch from the main branch
2. Follow the naming convention: `feature/{feature-name-or-id}`
3. Use meaningful names, for example: `feature/funding-items-apply-limit`

### Pull Request Process

1. Send a pull request to `develop`
2. Assign the PR to a peer for code review and approval
3. Once approved, the changes will be merged to `develop`

### Branch Management

- The `develop` branch contains all in-flight features
- **Do not delete** feature branches after merging to maintain history
